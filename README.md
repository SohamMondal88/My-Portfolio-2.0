## Overview

This repository powers my personal developer portfolio. It is designed as a fast, visual introduction for recruiters, founders, collaborators and potential clients.

## Features

- Responsive layout for mobile, tablet and desktop
- Project, skills, experience and education sections
- Smooth interactions and animated interface details
- Direct links to deployed projects, GitHub and LinkedIn
- Downloadable résumé
- Lightweight static architecture with no build step

## Built with

- Semantic HTML5
- Modern CSS3
- Vanilla JavaScript
- Vercel for deployment

## Run locally

Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/SohamMondal88/My-Portfolio-2.0.git
cd My-Portfolio-2.0
```

For a local development server, use VS Code Live Server or:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
